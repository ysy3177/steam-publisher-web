# Steam Publisher Web v0.2.0

기존 Windows 매크로를 복사하거나 수정하지 않고, 사용자 요구사항을 기준으로 새로 작성한 독립 웹 프로젝트입니다.

## 현재 기능
- DOCX 브라우저 내 분석
- KR / JP / EN / TW / CN / TH 언어 구간 분리
- RU = EN 매핑
- 언어별 제목/본문 미리보기
- DOCX 이미지/표 HTML 변환
- Steam 편집기 연결용 북마크 도우미
- Steam 편집기 읽기 전용 안전 진단

## v0.2.0 안전 진단에서 하는 것
- 편집 가능한 영역 탐색
- 제목 입력 후보 탐색
- 언어 선택 UI 후보 탐색
- 저장 버튼 후보 탐색
- 표시 중인 이미지 탐색
- 진단 결과를 Steam Publisher Web 탭으로 전송

## v0.2.0에서 하지 않는 것
- 제목 수정
- 본문 삭제/입력
- 이미지 삭제/교체
- 저장 버튼 클릭
- 공지 복제/발행

## 배너 보호 규칙
Steam 공지를 복제한 뒤 기존 상단 배너와 하단 배너는 유지합니다.
실제 자동화에서는 두 배너 사이의 기존 본문만 제거하고 DOCX의 해당 언어 본문을 삽입합니다.

## 사용 순서
1. DOCX를 분석합니다.
2. `Steam 연결 도우미` 버튼을 브라우저 북마크바로 끌어다 놓습니다.
3. Steam 공지 편집 URL을 넣고 `Steam 편집 페이지 열기`를 누릅니다.
4. 새로 열린 Steam 탭에서 북마크바의 `Steam 연결 도우미`를 클릭합니다.
5. 다시 웹 도구로 돌아와 `안전 진단 실행`을 누릅니다.
6. 결과를 확인한 뒤 실제 자동화용 선택자를 확정합니다.
