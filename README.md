# Steam Publisher Web

독립적으로 새로 작성한 웹 프로젝트의 1차 버전입니다.

## 현재 기능
- DOCX 파일을 브라우저에서 직접 읽기
- `KR / JP / EN / TW / CN / TH` 구간 자동 분리
- Steam 지원 언어 매핑
- `RU = EN` 예외 규칙
- 언어별 제목 / 본문 미리보기
- DOCX 안의 이미지와 표를 HTML 미리보기로 변환

## 아직 포함되지 않은 기능
- Steamworks 자동 로그인
- 기존 공지 복제
- 전 언어 선택
- 언어 드롭다운 자동 변경
- 기존 제목/본문 삭제
- DOCX 리치 콘텐츠 자동 붙여넣기
- 저장 및 검수

이 기능들은 다음 단계에서 별도의 브라우저 자동화 백엔드로 연결합니다.

## GitHub Pages에서 실행
저장소의 Settings > Pages에서
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

로 설정하면 정적 웹페이지로 실행할 수 있습니다.

> 주의: 이 1차 버전은 외부 서버에 DOCX를 업로드하지 않습니다.
> DOCX 처리는 사용자의 브라우저 안에서 수행됩니다.
