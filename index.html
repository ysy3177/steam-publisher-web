Steam Publisher Web

DOCX 다국어 공지를 Steam 편집기에 적용합니다.

v0.8.1

1. DOCX 불러오기

선택된 파일 없음

2. 언어 상태

체크된 언어만 Steam에 적용됩니다. 체크 해제한 언어는 건드리지 않습니다.
러시아어(RU)는 영어(EN) 내용을 사용합니다.

DOCX를 선택한 뒤 분석을 눌러주세요.

3. Steam 연결

최초 1회 extension 폴더를 Chrome 확장 프로그램에 등록 필요합니다.

확장 프로그램 등록 방법 extension 폴더 다운로드
Chrome 확장 프로그램 관리 페이지
chrome://extensions
  1. extension 폴더 다운로드를 눌러 ZIP 파일을 받습니다.
  2. ZIP 파일의 압축을 풉니다.
  3. 주소 복사를 누른 뒤 Chrome 주소창에 붙여넣고 Enter를 누릅니다.
  4. 오른쪽 위 개발자 모드를 켭니다.
  5. 압축해제된 확장 프로그램을 로드를 누릅니다.
  6. 방금 압축을 푼 extension 폴더를 선택합니다.
  7. 확장 프로그램 로드 후 새로고침하여 이용해 주세요.

※ 선택한 폴더 안에 manifest.json 파일이 바로 보여야 정상입니다.

① 웹페이지 연결확인 전
② 확장 프로그램 실행확인 전
③ Steam 탭 발견확인 전
④ 편집 화면 확인확인 전
상태: 대기 DOCX 분석과 Steam 연결이 완료되면 공지를 적용할 수 있습니다.
