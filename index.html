3. Steam 편집기 안전 진단

북마크 도우미 대신 Chrome 확장 프로그램으로 Steam 탭과 연결합니다. 마우스/키보드는 점유하지 않습니다.

읽기 전용 진단
배너 보호 규칙 상단 배너와 하단 배너는 그대로 유지하고, 두 배너 사이 본문만 교체하도록 설계합니다.

A. Chrome 확장 프로그램 연결

ZIP 안의 extension 폴더를 Chrome 확장 프로그램에 한 번만 등록하면 됩니다.

① 웹페이지 연결확인 전
② 확장 프로그램 실행확인 전
③ Steam 탭 발견확인 전
④ 편집 화면 확인확인 전

확장 프로그램은 Steam 탭의 DOM만 읽거나 수정합니다. Windows 마우스/키보드 제어는 사용하지 않습니다.

B. 테스트용 Steam 복제 공지 열기

복제해 둔 테스트 공지의 수정 화면을 Chrome 탭으로 열어 둡니다. 게시 중인 원본 공지는 사용하지 않습니다.

안전 진단/경계 확인은 읽기 전용입니다. 한국어 미저장 교체 테스트는 KR만, 7개 언어 미저장 순환 테스트는 KR→EN→JP→CN→TW→TH→RU 순서로 언어를 전환하며 화면에만 적용합니다. 저장/게시 버튼은 누르지 않습니다.

확장 프로그램이 연결되면 Steam 편집기 진단 결과가 여기에 표시됩니다.

다음 단계

진단 결과로 Steam 편집기의 실제 구조를 확인한 뒤, 복제 → 전체 언어 선택 → 제목 교체 → 상·하단 배너 사이 본문만 교체 → 저장 자동화를 연결합니다.
